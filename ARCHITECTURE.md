# FooterMenu Component - Clean Architecture

## 📁 Project Structure

```
src/
├── shared/           # Общие компоненты и утилиты
│   ├── types/       # TypeScript типы
│   │   └── menu.ts  # Типы для меню
│   └── ui/          # UI компоненты
│       └── icons.tsx # Иконки меню
├── entities/        # Бизнес-сущности
│   └── menu/        # Сущность меню
│       ├── menu-data.ts # Данные меню
│       └── index.ts
├── widgets/         # Сложные компоненты
│   └── footer-menu/ # Компонент нижнего меню
│       ├── footer-menu.tsx # Главный компонент
│       └── index.ts
└── lib/            # Утилиты библиотек
    └── utils.ts    # Вспомогательные функции
```

## 🎨 Компонент FooterMenu

Нижнее меню навигации с переключением между разделами, созданное на основе SVG шаблона.

### Основные возможности:

- ✅ **Интерактивное переключение** между пунктами меню
- ✅ **Плавные анимации** переходов (duration-200)
- ✅ **Стилизация из шаблона**:
  - Активный цвет: `#008D80`
  - Неактивный цвет: `#919191`
  - Фон: `#F4F5F7`
- ✅ **Responsive дизайн** с максимальной шириной 390px
- ✅ **Фиксированное положение** внизу экрана
- ✅ **Clean Architecture** - четкое разделение слоев

### Пункты меню:

1. **Okty.AI** (Docs) - документация
2. **Pay by Crypto** - криптоплатежи
3. **Neddo** - чат
4. **fpmnu** - профиль

## 🏗️ Clean Architecture Layers

### 1. Shared Layer (Общий слой)
Переиспользуемые компоненты и типы:
- `types/menu.ts` - интерфейсы MenuItem и MenuItemId
- `ui/icons.tsx` - React компоненты иконок

### 2. Entities Layer (Слой сущностей)
Бизнес-логика и данные:
- `menu/menu-data.ts` - конфигурация пунктов меню

### 3. Widgets Layer (Слой виджетов)
Сложные UI компоненты:
- `footer-menu/footer-menu.tsx` - главный компонент с логикой переключения

## 🎯 Использование

```tsx
import { FooterMenu } from '@/widgets/footer-menu';

export default function Layout({ children }) {
  return (
    <>
      {children}
      <FooterMenu />
    </>
  );
}
```

## 🛠️ Технологии

- **Next.js 16** - React фреймворк
- **TypeScript** - типизация
- **Tailwind CSS 4** - стилизация
- **shadcn/ui** - UI компоненты
- **clsx + tailwind-merge** - условные стили

## 🎨 Стилизация

Компонент использует цвета из SVG шаблона:
- Активный элемент: `text-[#008D80]`
- Неактивный элемент: `text-[#919191]`
- Фон меню: `bg-[#F4F5F7]`
- Радиус скругления: `rounded-t-[26px]`

## 🔄 Состояние

Компонент управляет состоянием активной вкладки через `useState`:
```tsx
const [activeTab, setActiveTab] = useState<MenuItemId>('docs');
```

## 📱 Адаптивность

- Фиксированное положение внизу экрана
- Максимальная ширина 390px (как в шаблоне)
- Центрирование контента
- Отступы для контента страницы (`pb-24`)
